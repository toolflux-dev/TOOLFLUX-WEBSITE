# CONTRACT STRIKE — Design Spec
*2026-07-12 · Approved by owner ("GO — build it as designed")*

## Concept

A solo career-mode mobile game (phone PWA) that gamifies running TOOLFLUX with CS2/GTA5 mechanics. Zoho Books is the referee: business milestones auto-verify against real data. CS2 is **theme only** (no Steam integration). Colorful static UI, **no dynamic animation**. A character — **Agent SPAHAN** — visibly wins and upgrades as the business grows.

## Decisions locked in Q&A

| Question | Decision |
|---|---|
| Verification | Auto-verify from Zoho Books; manual missions self-confirmed |
| CS2 | Theme only |
| Prizes | Self-set treat shop (seeded with suggestions) + in-game progression |
| Players | Solo |
| Character | Claude-designed: Agent SPAHAN, flat-vector operator |
| Rank system | Both: seasonal FLUX RATING (can drop) + permanent CAREER RANK |
| Questions | Insert-selection trivia w/ AI coaching, know-your-numbers, decision prompts, trade trivia |
| Season 1 arcs | Beat record month, vendor-code heists (multiple), collections cleanup, product-line launch |
| Rhythm | Open-ended, streak = played today |
| Session size | Quick hits 3–5 min |
| Name | **CONTRACT STRIKE** |

## Architecture

Same stack as machlog/EDGE LAB:

- **`contract-strike.html`** — single-file mobile PWA. All game logic client-side. State in localStorage (`cstrike_state`, `cstrike_settings`). Views: HQ · MISSIONS · RANGE · EMPIRE · SHOP (+ SETUP behind gear icon).
- **`contract-strike-sync.gs`** — Google Apps Script Web App. Script Properties hold: `ANTHROPIC_API_KEY`, `ZOHO_CLIENT_ID`, `ZOHO_CLIENT_SECRET`, `ZOHO_REFRESH_TOKEN`, `ZOHO_ORG_ID`. Endpoints (POST text/plain JSON, same contract style as edgelab-sync.gs):
  - `GET ?action=ping` → `{ok, hasKey, hasZoho}`
  - `POST {action:"sync"}` → `{ok, kpi}` — pulls Zoho Books (India DC: accounts.zoho.in token refresh, www.zohoapis.in/books/v3): 13-month revenue series, current-month revenue + invoice count, receivables total + overdue invoice list (top 10 w/ customer, amount, days), customers w/ first-invoice date (new-customer detection), last-invoice date per active customer (quiet-account detection), heist-target name match (first invoice to target = heist verified). KPI snapshot also logged to a Sheet tab for history.
  - `POST {action:"trivia", kind:"insert"|"trade", recent:[topics]}` → one MCQ generated by `claude-fable-5` (json_schema; fallback `claude-opus-4-8`): scenario, 4 options, correct index, per-option coaching that *teaches* when wrong. TFX grade lineup in system prompt.
  - `POST {action:"backup", state}` / `GET ?action=restore` → game-state JSON to/from Sheet (phone-loss recovery).
- **`contract-strike.webmanifest`** — installable, portrait, reuses icon-192/512.
- Offline: fully playable without backend (manual missions, cached KPIs, built-in offline question bank). AI trivia + sync need network.

## Game systems

### Career Rank (permanent, XP-based, 18 steps)
Apprentice I–IV → Operator I–IV → Specialist I–IV → Veteran I–III → Supplier Elite I–II → **GLOBAL ELITE SUPPLIER**.
Owner starts at **Operator III** — calibrated from real history (₹1.47Cr lifetime, 77 customers, 3 years). XP sources: daily play 10–25, side mission 15–50, prep mission 100, heist main 500–1500, trivia 10–25, Zoho-verified monthly milestones 100–300. XP never decreases.

### FLUX RATING (seasonal, 1,000–30,000, can DROP)
Recomputed on every sync from KPI components: revenue pace vs trailing-3-month average, progress vs record month, new customers this season, receivables health (total + overdue count vs baseline), invoice velocity. Weighted sum → rating; delta since last sync shown Premier-style (+340 / −220). Season = quarter (S1 = Jul–Sep 2026); recalibrates at season start.

### Missions
- **Heists** (GTA5 structure): prep missions (manual check-off) must ALL clear before the **main mission** unlocks; mains auto-verify from Zoho where possible. Completing a heist = big XP/FLUX payout + full-screen static victory scene.
- **Side missions**: generated locally from synced KPI data (overdue invoice chase, quiet-account revival, weekly invoice-count target) + owner-added custom tasks. Zoho-derived completions auto-verify on next sync; custom ones self-tick.

### Season 1 heist board (seeded)
1. **THE RECORD** — month revenue > ₹14,87,891 (Nov 2025 record). Auto-verified. Preps: pipeline audit, 3 quotes out, reactivate 2 quiet accounts, dispatch plan. *(unlocked)*
2. **VENDOR CODE: ASHOK IRON WORKS** (Belgaum — blocks/heads/housings, large in-house machining lines; from prospect DB). Preps: intro contact → meeting/visit → trial run approved → vendor registration submitted → first PO. Main auto-verifies on first Zoho invoice matching "Ashok Iron". *(unlocked)*
3. **VENDOR CODE: BELGAUM FERROCAST (BFPL)** — machined castings for hydraulics/pumps/valves. *(locked until Specialist I or Heist 2 complete)*
4. **VENDOR CODE: BELGAUM AQUA VALVES** — industrial valves (leverages Microfinish/BDK references). *(locked until Specialist I or Heist 2 complete)*
5. **THE RECOVERY** — receivables baseline ₹12.35L / 59 overdue; milestone every ₹2L recovered, finale < ₹2L outstanding. Auto-verified. *(unlocked)*
6. **PRODUCT LINE LAUNCH** — line name editable in-app; preps: samples, price list, launch stock; main: first 5 customers invoiced with the new line. *(locked until Operator IV)*

Targets sourced from the owner's Notion "TOOLFLUX Prospects" DB (scanned 2026-07-11); names editable in-app.

### THE RANGE (quiz arena)
- **Insert Selection** (AI): real machining scenario → pick insert/grade → wrong answers get coaching. +25 XP / +50 FLUX correct; +10 FLUX consolation.
- **Trade Trivia** (AI or offline bank): ISO codes, coatings, cutting data.
- **Know-Your-Numbers** (local, from KPI cache): "Who owes you most right now?" +15 XP.
- **Decision Prompt** (local): pick which overdue/quiet account to attack today → answering spawns that side mission.
Daily cap ~5 questions (3–5 min sessions); streak = any play today, multiplies XP (up to ×1.5).

### Economy & Treat Shop
FLUX coins earned alongside XP. Shop seeded (all editable): Tier 1 – 500 (dessert run, movie night, 1hr guilt-free CS2 marathon); Tier 2 – 2,500 (dinner out, new game, accessory); Tier 3 – 10,000 (gadget, weekend trip); **Boss tier – 25,000, locked until Veteran I** (owner-defined big reward). Purchases deduct FLUX and log to a trophy ledger.

### Locks (rank-gated content)
Heists 3/4 (Specialist I), Heist 6 (Operator IV), Empire INTEL ROOM — customer-level analytics (Operator IV), Empire WAR ROOM — forecast view (Specialist II), Boss-tier shop (Veteran I), character gear/backdrop tiers (each rank tier). Locked cards show silhouette + "REACH <RANK> TO UNLOCK".

### Agent SPAHAN (character)
Flat-vector SVG operator: navy tactical jacket, safety-orange accents, carbide-insert chest emblem, headset. Gear layers unlock by rank tier (watch → gloves → jacket upgrade → briefcase → gold visor). Backdrop scenes upgrade: bare workshop → office → dispatch bay → glass HQ. Static victory pose overlay on heist completion. No animation beyond simple CSS transitions.

### Screens
- **HQ**: character + backdrop, career rank badge, FLUX RATING + delta, streak, today's contracts (quick missions + 1 decision prompt), sync status.
- **MISSIONS**: heist board (prep checklists → main), side missions, add-custom-task.
- **RANGE**: question cards, one at a time, coaching reveal.
- **EMPIRE**: revenue race vs record (this month pace bar), 13-month revenue chart (static SVG), receivables gauge, new-customer count; INTEL/WAR rooms rank-gated.
- **SHOP**: treat shop tiers + gear showcase + trophy ledger.
- **SETUP** (gear icon): backend URL, test, sync now, backup/restore, edit heist targets, edit treats.

## Error handling
- No backend URL / offline → banner "OFFLINE MODE — Zoho verification paused", all manual features work.
- Sync failure → keep last KPI cache with timestamp; rating unchanged.
- Trivia API failure → fall back to offline question bank.
- All GAS endpoints return `{ok:false, error}` on failure; client surfaces in a toast.

## Non-goals (v1)
No real CS2 stat tracking, no multiplayer/leaderboard, no push notifications, no server-side auth beyond the GAS URL, no animation engine.

## Deployment (owner, ~10 min)
1. Create Google Sheet "TOOLFLUX — CONTRACT STRIKE"; paste ID in .gs.
2. script.google.com → paste contract-strike-sync.gs → Script Properties: `ANTHROPIC_API_KEY` + 4 Zoho values (self-client guide in CONTRACT-STRIKE-SETUP.md) → Deploy Web App (Anyone).
3. Open contract-strike.html on phone → SETUP → paste /exec URL → TEST → SYNC.
